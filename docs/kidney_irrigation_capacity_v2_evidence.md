# 新容量模型的医学证据与适用边界

日期：2026-10-14。用途：支持需求调整和后续标定设计；不提供临床操作阈值，不把实验压力端点当作人体安全标准。

## 1. 本例已知与未知

用户提供：成人，无结石梗阻或肾积水；CT 是否为增强排泄期未知；没有注排水前后影像或压力—容量实测数据。这些是用户说明，不是本轮影像诊断结论。

单份 CT 参考几何不能同时确定无灌注时的残余容量、最大正常容量、壁的顺应性、压力基线及充排水滞后。当前还没有同一解剖测量范围、相同出口条件和已知生理状态下的个体标定。

## 3. 对容量目标的结论

本轮检索未找到可以直接用于**这份成人、无梗阻 CT、当前人工接口模型**的正常 V_min 和 V_max。不能把“没有找到可直接移植的数据”理解为医学上不存在任何测量；结论仅限本次证据与本例输入条件。

M1 最接近成人集合系统灌注，但仍是离体／尸体实验，存在密封、温度、漏液、初始体积及加载历史差异。M2 提供成人术中压力，未提供本例的完整容量曲线。M5 和 M6 分别受到年龄、解剖范围或测量指标限制。因此本轮保留：

| 量 | 当前状态 | 确定所需条件 |
| --- | --- | --- |
| 完整计算网格参考体积 | 可由本轮几何核算获得 | 保持单位和参考数组不变 |
| 解剖有效 V_reference | 未确定 | 审核天然腔室范围、UPJ／输尿管截止面及人工孔的虚拟补壁 |
| 正常 V_min、V_max | 未确定 | 同域的个体影像／实验标定，或明确适用的成人数据及专家批准的迁移规则 |
| ΔV_contract、ΔV_expand | 未确定 | 前三者明确之后计算；不预设对称 |
| 压力、顺应性、真实流量和滞后参数 | 未确定 | 同步压力、流入／流出、初始体积、出口条件及时间记录 |

如暂时无法取得个体数据，可选择**待标定演示模型**：由用户／专业审核者明确批准不对称的演示容量目标与局部响应假设，逐项注明来源和适用范围。通过几何门禁只能证明指定模型在工程上可播放，不能证明目标属于正常生理范围。

## 4. 后续资料优先级

1. 优先找回原始分割、添加人工通道前的天然腔体、CT 时相和空间标定信息；不需要在聊天中提供身份资料。
2. 若有同一个体的不同灌注状态影像，在相同解剖域重复分割和测容，记录体位、补液、膀胱／出口及检查时点。
3. 如通过合规研究取得灌注实验数据，需同时记录初始腔体状态、压力、流入与流出、器械占位和漏液；实验设计及允许压力范围由医学研究负责人决定。
4. 若只能使用成人群体文献数据，应取得测量范围及状态明确的全文数据，建立个体差异范围，明确其不是患者特异校准。

不能用肾实质总体积、肾盂前后径、儿童肾积水容量、设备灌注袋压力或一个常见“肾盂几毫升”的概括值代替上述标定。
