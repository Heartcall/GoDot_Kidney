# N1.5-M 标定设计：操作性端点、域映射与可识别性

版本：2026-10-15-v1。研究模型；不包含患者拟合或临床加载方案。真实参数继续为 null；D2批准记录与几何均保持不变。

## 1. 量与操作性条件

`V_R = 16.805962087430178 mL` 是批准D2的Reference几何积分。`V_-`、`V_+` 是待估计、待批准的**特定条件下**两个容量端点；先定义条件，再估计体积，不能先选百分比再寻找医学解释。

定义条件向量 `c`：人群/个体、侧别、健康筛查、成像与分割范围、体位／呼吸时相、补液／利尿状态、采集与排尿时间、膀胱和出口条件、器械占位、压力测点/零点、加载速率/历史、观察窗口。未知保持 null；正常A没有器械的事实也需记录，不能从“灌注前”推断。B是内镜存在下的受控状态，绝不能与A共享未验证的容量—压力函数。

候选定义供医学人员与用户选择，**本轮不作选择**：

| 定义 | 数学对象 | 解释边界 |
| --- | --- | --- |
| 指定两个状态的代表容量 | `V_-=E[V_D2 | c_A-, i]`、`V_+=E[V_D2 | c_A+, i]` | 医学人员先指定状态、时间窗及代表值规则；均值不是绝对极限 |
| 指定健康条件集合的包络 | `I_A(i)=range_or_quantiles(V_D2 | c∈C_A, i)` | 仅对观测覆盖的条件集合有效；分位水平和周期采样须预先批准 |
| 指定B器械/出口条件的两端 | `V_D2(c_B-,h_-)`、`V_D2(c_B+,h_+)` | 规定器械、通路、观察时间及历史h；不是损伤上限、设备压力上限或封闭试验终点 |
| 有滞后的加载/卸载端点 | `V(P,c,h=loading)` 与 `V(P,c,h=unloading)` | 相同压力可以对应不同容量；不默认排水后立刻回到无液体状态 |

条件定义需要医学负责人审议；本文件没有推荐某种饮水、药物、侵入性测压或压力加载的具体操作。任何新增受试者研究由有资质的医学负责人及伦理程序决定，当前优先审核已有合法资料。

未来几何参数 `s=-1,0,+1` 标记 Contracted/Reference/Expanded；它是**几何编码**。时间进度τ、观测生理条件c、容量V、压力P、累计流入与净滞留量分别保存。Reference的生理状态未知，不预设为c范围中点、V算术中点或正常50%。下面合成测试的状态x已知只是测试前提，不代表本例已知这些状态。

## 2. 医学测量域与D2的映射

| 医学测量 | D2差异 | 现有几何能做什么／不能做什么 |
| --- | --- | --- |
| 仅肾盂 | D2还包含肾盏、连接空间、保留B31/B32根部及封闭末端 | 现有编号不是医学肾盂标签；N1分区仍候选，不能按MAIN冒充全部肾盂并指定系数 |
| 肾盂肾盏三维腔内掩码 | 需核对UPJ、输尿管、肾盏末端与重建封口 | 有D2源面、重心映射及虚拟封口；无临床同域掩码，就没有可验证的体积补偿项 |
| UPJ截止或包含近段输尿管 | D2采用已批准BLADDER截面及其上游空间 | 可追溯工程截面中心、法向、截环和排除面；不能把它宣称为临床UPJ，不重新裁剪D2 |
| 置械／人工灌注入口 | D2有IN01/IN02工程入口与保留过渡空间 | 固定管壁不代表所有保留空间体积恒定；占位、流量计平面和管路储液须另有记录 |
| 天然肾盏终端／影像分辨率截止 | D2沿用T01～T22现有闭合面 | 能追溯模型边界；没有影像就不能分辨真实末端、分割截断与部分容积偏差 |
| 二维AP径／椭球／IVP公式 | 并非D2的真实三维边界积分 | 长径/分级不唯一决定体积，公式误差需独立验证；禁止任意乘系数 |
| 流入体积积分 | 注入量不是腔内绝对容量，也不是净滞留量 | 需初始量、流出、漏液/吸收、内源尿液和外部储液；之后仍要空间域与器械占位换算 |
| whole kidney / renal sinus ROI | 实质或脂肪/血管混合域，不是腔内空间 | 不能用这些ROI的mL直接标定D2；M10/M24/M28为明确反例 |

若临床域M与D2确实在同一状态、同一可审计坐标系，可通过空间集合计算：

`b_domain(c) = V_M(c) - V_D2(c) = |M(c)\D2(c)| - |D2(c)\M(c)|`。

这是测量域差的定义，**不是当前已算出的校正值**。需要实际临床边界、可靠对应及分割误差；几何注册后也不能仅用最近点认定解剖同源。体积应在各原始物理尺度下计算；非刚性配准若用于体积变换，必须审核Jacobian和尺度，不能用配准把体积差“对齐掉”。

已保留的人工根部包含天然连接共用空间，缺乏材料标签时 `b_domain` 可能不可识别。即使Reference能估计补偿，状态依赖性仍未知；不能认定 `b_domain(c_-)=b_domain(c_+)`。若只能得到经证据支持的上下界，就做集合传播；没有证据给界则保持不可直接标定。D2本身不因医学映射而回改。

## 3. 方案A：同个体多状态三维影像（优先）

输入现成、去身份化且使用权限明确的原始图像/空间元数据、分割、采集状态与端点条件。审核步骤：

1. 核对是否真为同个体、同侧、同状态定义；比较CT时相、MR序列或经验证3D超声覆盖，不能将增强对比变化当真实形变。
2. 每次使用同一测量边界约定，配准建立源面/标签对应；保留不能映射的人工连接空间及状态依赖补偿。
3. 在各次原生mm尺度下三维计容；重复独立分割／重复采集用于区分读者误差、重测误差与真实时间变化。双肾、同人的多时点是相关观测。
4. 预先定义端点覆盖证据。两张影像的最小/最大只叫“已观测范围”，没有覆盖就不升级为操作性端点。Reference旧图状态未知，不能硬作为第三个已知生理加载状态。
5. 两端各有直接有效观测时可分别估计其容量，不必先强拟合整条P–V曲线。重复观测用于区间；多少次足以达到精度要根据重复性与预期误差设计，当前不能凭空固定样本量。

一个观测模型为：

`Y_ijk = V_i,D2(c_j,h_j) + b_domain,j + b_seg,method + r_reader,k + ε_ijk`。

`Y`是实际测量域M中观测容量，`b_domain=V_M−V_D2`；分割偏差和方法误差与数值积分误差分开。尺度误差是乘性项：若长度倍率为a，体积倍率为a³；小误差近似 `δV/V≈3δa/a`，不能只用三角积分重复一致性评估临床误差。

成对差：`ΔY = ΔV_D2 + Δb_domain + Δb_seg + Δε`。公共偏差只有在有证据确为状态不变时抵消。若临床域不能与工程根部对齐，即便个体有多时点，也只能先报告临床域结果和映射阻塞。

## 4. 方案B：健康成人群体参考

优先获得测量域、状态和方法一致的**健康成人**原始个体数据／完整分布。年龄、性别、侧别、体型、补液/膀胱/姿势应记录；本例未知协变量不能从形状猜测。儿童、动物、病理、术中和离体数据不与健康成年人平均。

可候选模型：`V_ij = μ(c_j,z_i) + a_i + g_i(c_j) + b_study/domain + ε_ij`，其中a为个体差异，g为状态响应，侧别可嵌套个体。先解决各研究域/方法差异，之后才有分层分析的意义。没有配对动态资料时，g以及两端容量的协方差不可识别；静态群体百分位不是个体动态容量端点。

完整均值/SD也不足以推导真实百分位或区间，除非分布假设有证据且经批准；摘要没有原始分布时不能自动假定正态。两肾不算两名独立受试者。跨论文队列重叠未核实时不当独立样本。M03/M13/M27是补全文／方法数据的优先线索，当前没有形成可用的统一健康成人样本。

即使将来得到群体参考区间，对本例也只能报告条件匹配的**预测**与迁移限制，不能改称患者实测或唯一Vmin/Vmax。不能为得到有限区间给未知域差任意正态先验。

## 5. 方案C：压力—容量／流入流出联合标定

仅分析合法取得的既有实验/临床数据。先明确控制体和流量计位置；流入、流出、漏液、组织吸收、死腔和内源尿液不能重复计数。

基本守恒：

`V_fluid(t)=V_fluid,0 + ∫[Q_in + Q_urine − Q_out − Q_leak/absorption − dV_external_storage/dt]dt`。

当Qin已包含所有生理流入时，不另加Qurine。独立漏液/吸收不明时不能记0。传感器时延、零漂、秤的密度换算、流量单位（mL/min vs mL/s）、同步误差与缺测区间都需要账目。

几何容量与液体滞留量的关系还需：

`V_lumen,M = V_fluid,M + V_device + V_gas + V_stone/other_occupancy`；

`V_lumen,D2 = V_lumen,M − b_domain`。

未测量绝对初始容量，只能识别变化量，不能用16.805962直接替代术中初始液量；Reference旧扫描不是同步液体基线。装置储液与患者腔内滞留分开，设备供压不等于局部腔内压力；测点/零点/体位差需要记录。

候选关系包括单调非参数 `V=f(P,c,h)`、分段模型或带独立初始偏移的非线性形式，例如 `P−P0=A[exp(B(V−V0))−1]`。这是**模型族待检验**，没有本例A/B/P0/V0参数。仅压力或稳态压力—流量比可以约束某些阻力，不能唯一决定储液顺应性 `C=dV/dP`。非平衡时dV/dP沿动态轨迹也不一定是静态材料顺应性。

加载与卸载先分开；同一P不同V、速率依赖或历史残余说明单值函数可能不足。可比较观测支持范围内的单调曲线、非线性形式与滞后状态模型，利用交叉验证、残差和重复加载资料评估；先验／模型复杂度超过数据时保留非参数区间或待定，禁止外推成“最大容量”。来源中封闭出口、温度、死亡后状态及漏液使迁移到健康A尤其受限。[人体离体研究](https://e-century.us/files/ajceu/14/2/ajceu0170543.pdf)、[Williams作者稿](https://people.maths.ox.ac.uk/moulton/Papers/FullSystemPaperFinal.pdf)。

## 6. 当前可识别性与区间解释

| 数据 | 能约束 | 不能约束 |
| --- | --- | --- |
| 当前单D2 Reference | 批准模型在该形态的几何积分与工程边界 | 真实状态c_R、两个端点、P、C、真实流量、患者正常百分位 |
| 两个条件明确、同域影像 | 已观测条件间的容量差及端点条件的代表值（若覆盖成立） | 未观测生理极限、完整非线性或滞后函数 |
| 多时点但公共域偏差未知 | 偏差状态不变时可能识别差值 | 绝对端点与偏差互相混淆；状态依赖偏差还会污染差值 |
| 完整净流量，无Vinitial | 受误差约束的ΔV | 绝对容量；遗漏漏液则ΔV也不可识别 |
| 只有术中P/设备P | 指定条件下的压力行为 | 无独立容量／流量／出口观测时的P–V函数、健康容量上下界 |

合成二次观察模型 `Y=a+b*x+c*x²` 只是秩检验示例：一个已知x=0观测矩阵秩1/3；两状态秩2/3；三个不同已知状态可满秩；再加未知共同域偏差列后秩3/4。其“三状态”不是临床充分性保证；当前Reference连实际生理x也未知。不能用病理或动物先验消除这种缺失，假装获得患者证据。

| 表达 | 含义及使用前提 |
| --- | --- |
| 置信区间 | 对规定估计量和重复抽样过程的不确定性；不是95%个体容量落在其中 |
| 预测区间 | 条件匹配新个体／新时点的变化，包含个体／状态差异，通常不能用均值CI替代 |
| 后验分布／可信区间 | 条件于模型、似然及先验；不可识别时可能主要由先验驱动，需披露敏感性 |
| 可行区间 | 在有证据支持的误差／域差界下所有兼容解；若缺界可无界／不可确定，不硬造有限界 |
| 数值积分重复误差 | 只反映同网格计算一致性；不是分割、尺度、域映射、临床状态或端点误差 |

当前只能给出几何参考值，**没有可信的本例端点数值区间**。合成Monte Carlo的概率区间来自人为测试分布，不可用于患者。本版本没有实际疾病、性别、压力或正常容量推测。

## 7. 输入／输出结构与审批门禁

字段模板见新版本 [calibration_input_template.json](../godot_sim/deformation/capacity_v2_n15_m_v1/calibration_input_template.json)。每次观测至少包括来源/许可/哈希、去身份化个体与侧别编码、状态及时间窗、方法、物理尺度、测量域和边界证据、容量及单位、重复／读者、误差相关结构；C另含同步P/Q/漏液/占位及初始容量。未知允许显式null，但会阻止相应标定结论。

未来输出应为版本化候选：端点条件、体积估计、区间类型／覆盖水平、域映射模型、数据来源、方法／误差模型、外推／识别诊断、Reference夹持检查、医学及用户批准。**研究原型不提供真实端点写入函数**；`approval_gate`只列阻塞原因，始终返回 `approved=false`。

正式赋值必须逐项通过：

1. 医学与用户批准A或B的操作性端点定义、适用人群、时间／历史与边界条件；不是笼统“正常最大”。
2. 合法资料、可核实原始来源和版本/哈希；合成数据永远不能通过，E3/E4不能供本例端点；E2缺口须解决。
3. 同域或有独立审核的D2映射与不确定性；不能用任意系数、未批准分区或未解净截面积补齐。
4. 两端覆盖、足够独立观测与重复性；对遗漏、偏差、队列差异和模型结构做敏感性分析。
5. 估计量可识别且区间解释明确；病理/离体/儿童迁移需独立证据，不能仅按年龄／体重缩放。
6. 检查 `V_- < V_R < V_+` 是否得到证据支持；若不成立或区间重叠使关系不确定，提交状态定义复审，不强行对称化或改变Reference。
7. 医学负责人和用户审查签署：适用范围、剩余偏差、区间、端点与模型版本。**端点批准不等于N2实现批准**。

## 8. 合成原型和后续衔接

[n15m_calibration.py](../godot_sim/tools/capacity_v2/n15m_calibration.py)仅接受 `SYNTHETIC_TEST_ONLY`。单一合成夹具使用与本例无关的测试容量，不调用旧0.2mm工程场；验证非对称性、域偏差、漏液、秩、历史分支和拒绝外推。拟合所得91/100/115 mL等值**仅在synthetic目录，是软件单元测试量，不是本例候选**。没有五组端点扫描。

原型采用NumPy加权最小二乘、显式守恒梯形积分和SciPy保形分段插值作流程验证；没有声称合成二次函数是生理规律，也未把它部署为正式标定软件。未来真实输入解析、质量控制和模型选择须另经授权与验证。

端点批准后才可向N2提供独立两侧容量约束 `V_D2(q_-)=V_-`、`V_D2(q_+)=V_+`。单一容量标量不能唯一确定局部位移，仍需N1区域尺度、保守未解截面、形状/拓扑/固定区与组织接触约束。必须实际积分、保留源面映射并验证连续区间，而不是把0.2mm旧场放大／取负。临床标定不能证明网格无穿越、真实壁厚、材料参数、内镜包络或路径安全。

N1.5-M之后先停在证据／方法审查。数据不足时继续文献全文／合法数据访问和映射研究，保持null，不以工程演示替代生理路线。不实施N2/N3、内镜集成、性能优化或视频。
