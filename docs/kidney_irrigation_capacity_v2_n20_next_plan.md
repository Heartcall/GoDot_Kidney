# N2.0 后的算法冻结与验证计划（待授权）

本轮结束后停在研究审核，**不自动开始正式 N2**。±30%目标保持原值；当前仅有更小幅度的离散候选，不足以冻结正式 Contracted／Expanded。

1. 审核主次响应分区、97个额外测量截环来源锚点、原型实际贡献、T_18面7680、组织共点93578相关保守半空间冲突。确认是否保留这些研究边界条件；这不是重新移动或重新批准 D2 截面。
2. 接触算法升级：将有限 VF／EE 接触特征及其参数连续追踪，替代对整个组织面施加无限半空间的过保守代理；保持139真实共点与远场。先让旧+8%、+15%回归在整个运动区间、所有接触与质量门禁下通过，再研究+30%，不得只以终态横向穿越降到0为依据。
3. 区域求解升级：把本轮启发式 mobility 缩减改为带容量梯度、可靠活动接触、局部质量和信赖域的联合／分块 SQP。允许已饱和区的合法切向整理或回退后再分配，不能只让已累积到极限的场继续加正向增量。统一中断恢复的活动集持久化与失活规则；本轮恢复只保留绑定行，不能保证与不中断搜索同路径。每次步长由连续非穿越或保守可证区间决定。
4. 收缩局部整理：扩大到有渐变边界的 patch，并联合组织求解；检查 float32 的实际显示坐标和非零裕量。本轮约1 nm的切向修正不能直接作为生产修复。只有有明确必要证据时，才另开统一拓扑重网格研究；仍保护原 Reference 与所有来源映射。
5. 测量封口：优先保留本轮连续固定材料截环方案，评估限制；如需要截环移动，先冻结一个统一连续模板及其边界映射，完整验证封口—壁相交与全过程体积，不能逐帧选择有利的三角化。禁止质心扇形替代和统计域漂移。
6. 认证门禁：精确／误差控制 CCD，永久接触流形处理，全部物理与测量面、共享特征、实际分支通道和端口检查；逐值恢复Reference、固定3675、139共点、全程原始相对面积／边梯度。保留医学与材料归属限制，不把普通表面距写成壁厚。
7. 只有达到批准容量且上述门禁通过，才建议用户另行批准正式 N2 资源冻结、独立 Godot 高幅度预览及实际 float32 接触复核。若仍未达到，输出可证明的模型／算法界限与阻塞，不自动把更小端点当作新目标。

正式资源候选应带算法版本、输入和模板哈希、求解日志、容量积分、全局与局部质量、连续检测证书及人工验收状态。P1/P2旧基准、医学null结论、D2、主场景及内镜碰撞均保持原样。

未来路径／器械净空、动态碰撞、18～19FPS性能整改和“外部变化→内镜路径”的视频仍是独立后续任务；本轮离线几何研究不提供这些安全或性能证明。
