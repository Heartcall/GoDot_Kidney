# N2.1-R 后续整改与冻结门禁（待批准）

本轮暂停等待用户审核。±30% 工程目标保留，不能将 −7.625%、+8%、+15% 夹具或约 +5% 失败提案改称最终端点。

1. **首先补齐连续认证范围。** 对移动共享单顶点的自交面对应进行分块精确认证；共享边／共享点共面重叠独立分类；完成 +15% 自身 CCD。增加 D2 封口—物理壁及封口自身的连续门禁。为实际 float32 量化运算轨迹设计保守位移包络或事件细分，不以源 binary64 端点仿射证书替代。保留所有未解析项，不强制分离原有合法接触。
2. **冻结可复现有限接触内核后再改联合求解。** 以旧 +8%、+15% 和 false-plane 93578 作为不同性质的夹具：前者必须从 Reference 连续安全推进，而不是仅保留 N2.0 热启动；后者要求始终保持139共点、不在场外施加面半空间。用 CCD 限制每个试探步，遇接触先激活／重定位有限特征，再重新求解总 q 和组织自由度。
3. **针对约 +5% 新提案的 69 对穿越定位。** 保留来源面号、交线长度、空间位置和 B_03／B_04／B_25／B_26／B_29 邻域证据，研究有限特征切换和新的接触覆盖。不得只缩小 mobility 或放宽容差。改善目标是新联合轨迹的所有门禁，而不是某一终态数量下降。局部线性 LP 可行不证明非线性接触空间可行。
4. **收缩整理只作研究基准。** R2 多 patch 的 float32 余量和容量保持可作为下一算法回归；补齐自身／封口／量化轨迹后，才判断 −7.625% 研究候选是否可成为连续安全的中间检查站。尚没有必要证据启动统一拓扑重网格，更不得仅对收缩态删点。
5. **97点边界只保留敏感性结论。** 当前 ±0.5% 对比没有证明它是主要容量瓶颈。若下一轮采用随动材料边界，须先冻结同一来源重心、封口连接表和全过程有效性；不能更换解剖截止位置或逐帧选对容量有利的封口。
6. **逐步研究用户目标，不先承诺可达。** 只有较小幅度的新联合轨迹、所有连续门禁和 float32 实际坐标通过，再推进更高幅度。每次记录实际 D2、区域容量梯度、接触饱和、局部质量与求解失败。若停止，区分算法不足、边界限制与已证明的几何不可行；不从一次停步推导全局极限。
7. **正式 N2 的前置冻结条件。** 双向目标实际 D2 积分达到批准误差；完整物理质量、固定3675、共点139、远场零、分支及端口连通、完整自交／相互连续碰撞、测量封口与容量连续性通过；所有来源／代码／模板／检查点版本固定；用户另行批准后才生成正式资源和独立 Godot 高幅度预览。此次不具备这些条件。

医学 null、F03／F04 材料归属、真实组织厚度、临床压力／流量继续未知。P2.3 的18～19 FPS、内镜包络与路径净空、动态碰撞和视频是独立后续事项，本轮没有处理或证明。
