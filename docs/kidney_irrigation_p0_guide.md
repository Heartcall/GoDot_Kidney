## 你现在进行的操作

### 第一步：确认原场景画面

1. 用上述 Godot 打开 `godot_sim/project.godot`。
2. 打开 `main.tscn`，运行项目，观察是否能看到粉色腔壁、灯光和内镜画面。
3. 按 `Esc` 可切换鼠标释放／捕获；`T` 控制现有自动巡航。先观察固定画面，再用巡航了解内部结构。
4. 记录有无黑屏、明显穿模、异常闪烁或运行错误。正常启动日志不是画面正确的充分证据。

本步产物：一张原内镜画面截图，以及“能正常显示／具体异常”的记录。

### 第二步：识别腔室和入口

我已准备 `godot_sim/irrigation_asset_check.tscn`，用于编辑器中的外部网格检查。

1. 停止运行，在 Godot 文件系统面板打开该检查场景。
2. 场景树选择蓝色的 `CavityReference`，按 `F` 聚焦选择的模型，在 3D 编辑视图旋转和缩放观察。
3. 初始只显示腔体。识别细长入口段、较宽腔室、分叉与末端分支；具体肾盂／肾盏标签以模型解剖核对为准。
4. 隐藏 `CavityReference`、显示 `TissueReference`，观察组织外形。可使用场景树可见性开关或 Inspector 的 `Visibility > Visible`。
5. 切换两者进行对照。两个网格的 Position、Rotation 均为零，Scale 均为一；保持这个共同坐标系，才能使用已有路径。

检查场景只用于编辑器 3D 视图核对，没有运行相机；原场景的运行入口仍是 `main.tscn`。

本步产物：一张腔体外部截图、一张组织外部截图；在腔体截图中标出入口、一个主扩张区、一个分支扩张区。

### 第三步：确定 P1 的三个约束

先只选一个主区域和一个分支，减少首次调试范围：

| 待确定项 | 选择原则 | 记录方式 |
| --- | --- | --- |
| 固定区 | 入口／连接段中希望保持位置稳定的范围 | 截图标注，后续转为顶点权重为零的区域 |
| 扩张区 | 主腔室和一个可辨认分支，避免第一轮同时处理所有末端 | 截图标注，后续转为控制场及区域权重 |
| 内镜观察位姿 | 能看到目标腔壁，留有壁距，扩张前后使用同一位置与方向 | 记录三维位置、方向、FOV，并先验证参考画面 |

检查报告提供了按壁距排序的相机候选，但这些只代表几何净空，尚未确认所属解剖区域和镜头内容，不能直接当作最终拍摄机位。

如果暂时不能确认解剖名称，可以使用“入口段／主腔室 A／分支 B”作为工作标签，待核对后命名。

