# P1.4：三态形态生成与插值验证

日期：2026-10-13。用户已认可 P1.3 的 MAIN、J_01、J_02、T_01～T_04 膨胀方向和连续性，B_32 保持不动。本轮 P1.4 实现及自动验证完成，等待用户验收。

## 结果与范围

只读取已认可的 P1.3 参考顶点、面索引和位移数组，使用同一个公式：

`x(u) = reference_vertices + u × displacement_P13`，`0 ≤ u ≤ 1`。

Reference=`x(0)`；Mid=`x(0.5)`；Expanded=`x(1)`。三态均有 25024 个顶点、50044 个三角面，共用完全相同的面索引。没有网格重建、重排、重采样，也没有重新求解位移场或重新生成掩码。最大位移分别为 0、0.1、0.2 mm。

原始 OBJ、72 个 Marker3D、标记 JSON、人工拓扑、resolved、P1.2 全部文件、P1.3 派生数据和 main.tscn 均未修改。开始本轮前，用户保存过 P1.3 预览场景，已有 `local_displacement_preview.tscn` 改动和 `.gd.uid` 文件；这些原样保留。本轮使用新的独立预览入口。

本轮仅加入用户要求的三态切换、0～1 滑块和调试显示；没有压力／流量、组织跟随、动态碰撞、注排水时间线或录像。

### Godot 精度处理

直接将原腔体坐标转换为 float32 时，参考形态会多检测出一对近接触三角面 `[11215,11218]`，属于坐标量化问题，不是充盈产生的问题。

最终实现只对**预览坐标**做平移，使用原点 `[16,16,-81] mm`；NumPy 三态和位移保持原坐标。中心路径、聚焦点和镜头同步平移，形状、长度、位移、编号均不变。这不是修改 OBJ 或 Marker3D。

对实际 float32 预览坐标，五档重新做退化、翻面、自交及固定点检查。上述额外近接触不再出现；全部状态只有同一对 B_24 既有自交。最大坐标量化误差约 `1.91e-6 mm`。

### 连续区间的额外诊断

除了五档采样，还直接计算线性顶点轨迹的多项式：

- 每个三角面的有向面积在原法线方向上的投影为二次式，逐面检查 `[0,1]` 的端点和极值。最小归一化投影为 **0.933987**，整个区间保持正值，未发生三角面面积归零或法线翻转。
- 带符号体积为三次式：`19723.0773625195 + 387.999415741863*u + 7.861900508885*u² + 0.008166065245*u³`。导数在 `[0,1]` 最小值 **387.999416 mm³／单位充盈度**，始终递增。
- 固定顶点的位移系数逐点严格为零，因此任意 `u` 下均不动。相邻位移差随 `u` 线性变化，其最大值不超过 Expanded。

这些是 float64 多项式数值诊断。**三角面之间的自交只在五档、两种精度下实际检查，尚无整个连续区间的自交证书。**有向面积正值、体积递增或水密性都不能替代全程自交检查。

```powershell

& 'E:/Apps/Conda/miniconda3/envs/FURS/python.exe' godot_sim/tools/test_cavity_morph_states.py

```

## Godot 验收操作

1. 打开 `godot_sim/project.godot`，双击 `res://cavity_morph_preview.tscn`，按 **F6**。
2. 按 **1 / 2 / 3** 或点击按钮切换 Reference / Mid / Expanded。镜头不随三态切换重置。
3. 拖动 **0～1 充盈度滑块**，查看任意中间位置；步长为 0.001，状态文字显示充盈度和对应最大位移。
4. 按 **4** 看位移大小，**5** 看方向，**6** 看参考蓝线叠加，**7** 看普通表面。色标统一为 0～0.2 mm，不随状态自动拉伸。黄色箭头仅辅助放大六倍，模型本身不放大位移。
5. 点击 MAIN、J_01、J_02、T_01～T_04 或三个接口按钮，保持局部视角比较三态。左键旋转、中键平移、滚轮缩放、R 回到全模型。
6. 重点观察 J_01、J_02 分叉、四个端帽、膀胱固定区到天然侧的过渡，以及两个注水接口是否在各档都保持不动。灰色表示零位移，具体固定／天然分类仍以 P1.2 掩码为准。

初始为 Reference、普通表面；Mid 和 Expanded 仍是 0.1／0.2 mm 小幅调试形态，建议在局部放大后切换比较。编辑器的充盈度属性也可用，但交互按钮和滑块在 F6 运行窗口中显示。
