# P1.2：B_31 / IN_01 过渡传播修复

本轮只修复 P1.2，当前等待用户在 Godot 中重新检查。未实施位移场、动态形变或 P1.3。

## 查看方式

1. 打开现有 Godot 项目与 `res://irrigation_mask_preview.tscn`，按 **F6**。
2. 点击 **“4 IN_01 单接口”**，再点击 **“B_31 接口”**；旋转观察 J_05 和各天然分支根部。
3. 按 **1** 查看合并区域类别，按 **2** 查看合并权重；按 **5**／**6** 分别查看 IN_02 与膀胱单接口。
4. 单接口模式的绿色表示“不受该接口影响”，其他人工管道的固定约束仍由合并掩码保持。

分类模式将所有 `0 < 权重 < 1` 顶点显示为橙色，包括接近 1 的极弱影响；判断权重大小请使用连续权重或单接口模式。

## 修复方法

原实现从固定管壁在整个连通表面图上计算距离，IN_01 的约 9.88 mm 支持长度会跨过 J_05 进入其他天然分支。

新实现保留原固定掩码，并按以下顺序生成 IN_01 的权重：

1. 用确认的拓扑建立 B_31／IN_01 通道核心，以及 J_05 相邻自然路径的短连接邻域。连接邻域长度按局部路径长度的 15% 计算，上限 1.5 mm；本数据中 B_12～B_18 为约 1.482 mm。
2. 沿表面边图生成 2.4 mm 平滑边带，并保留与 IN_01 固定管壁连通的部分。远近按表面连通距离判断，不能因空间靠近而跨入不相邻表面。
3. 将天然分支投影弧长超过“连接邻域＋平滑边带”的内部区域设为中性边界（权重 1）。从此边界向内生成平滑恢复函数，同时检查它与固定管壁的间距，避免在固定顶点上产生冲突。
4. 在受约束的连通区域中计算纵向响应，并与平滑支持函数结合；再对权重缺额进行带目标项的图 Laplacian 正则化。固定管壁严格约束为 0，中性天然内部严格约束为 1。
5. 最后合并各接口字段；IN_02 与膀胱接口仍使用原算法。

没有将所有非 B_31 最近路径顶点直接设为 1：J_05 附近的其他路径保留了连续混合权重，恢复函数也作用于 B_31 一侧的标签边界。固定顶点集合、源几何及路径归属均未改变。

离散网格仍有限制：IN_01 最大相邻顶点权重差约 0.425；过渡域外边界最大差约 0.00552；没有 0 到 1 的硬跳边。参数是几何掩码参数，不代表生理材料或压力参数。
