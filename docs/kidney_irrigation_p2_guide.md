# P2 工作指导：注排水演示控制与同步形变

日期：2026-10-14。依据：`kidney_irrigation_plan.md`、P1.5-R2 实际代码与数据，以及用户本轮正式人工验收结论。

**当前状态：P1.5-R2 的几何工程成果已经用户验收；可以进入 P2。本文件是工作指导，本轮没有实施 P2 控制器。** 历史 R2 报告和候选 manifest 中“待人工验收”的文字记录的是当时状态，保留原文；新的 P2 输入清单应记录此次验收。验收不代表已完成生理力学标定。

## 1. P2 要实现什么

将已验收的腔体与组织形态变成可交互的“参考 → 注水扩张 → 保持 → 排水回缩 → 恢复参考”演示。一个充盈度 `u∈[0,1]` 同时驱动两份网格，支持按钮、手动滑块、暂停和重复往返。

P2 不重新求解组织映射，不提高形变量，不接入真实压力或流量。原计划的 P3 负责主场景、内镜视角与碰撞集成，P4 负责展示时间线和录像；这些仍留在后续阶段。

本轮保留原始两个 OBJ、72 个 Marker3D、人工拓扑与 resolved 数据、P1.2 掩码、已验收腔体与组织位移、旧阶段结果、`main.tscn` 和项目启动场景。新增独立控制预览，避免干扰已有内镜系统。

运行时继续采用：

```text
cavity(u) = cavity_reference + u * approved_cavity_displacement
tissue(u) = tissue_reference + u * accepted_R2_tissue_displacement
```

Reference、Mid、Expanded 对应 `u=0、0.5、1`。腔体最大位移仍为 0.2 mm，组织最大位移约 0.196101 mm。`u=1` 是已验收调试形态的上限，不是生理最大容量。

复用现有共同显示原点 `[16,16,-81] mm`。原始参考坐标仍保存 OBJ 坐标；Godot 显示使用已验证的计算次序：`float32(reference-origin) + float32(u)*float32(displacement)`。两份网格必须使用相同坐标变换；保留既有三角面绕序转换。任何二进制打包应验证顶点顺序、面索引和精度。

### P2.1：先拆出可复用的形变播放模块

1. 新建输入清单，记录来源路径、形状、哈希、单位、显示原点、用户验收状态及幅度上限。
2. 将所需数据打包到新的 P2 运行目录。当前组织候选位于被 Git 忽略的 `analysis/` 中，不能只引用开发机诊断文件而不说明部署依赖；打包结果需独立重建并检查一致性。
3. 提取 `deformation_player`，公开 `set_filling(u)`。该模块只接收充盈度并更新两份网格，不决定注排水时序。
4. 每次从参考顶点计算当前坐标，禁止在上一帧坐标上累加位移。同一更新中先准备两份模型，再以同一个 `u` 提交显示。
5. 复用当前几何法线计算；先验证正确性再优化。不得仅混合端点法线就假定中间法线正确。
6. 保留稳定的不透明材质与剖切。新的日常运行模块不默认加载 R1 失败形态或昂贵的逐面诊断网格。

验证：`u=0、0.25、0.5、0.75、1` 与 R2 参考输出比较；面索引不变；固定腔体顶点全部零位移；组织 A 类共点与 E 类远区约束保持；返回 `u=0` 时显示坐标与初始坐标逐值一致。不要用原计划早期的 0.01 mm 恢复容差掩盖可避免的累计误差。

### P2.2：控制器只负责状态、时间和充盈度

建议状态及语义：

| 状态 | 充盈度行为 | 到达终点后的行为 |
| --- | --- | --- |
| REFERENCE：参考 | `u=0` | 等待命令 |
| FILLING：注水演示 | 从当前值平滑到目标值 | 转为 HOLDING |
| HOLDING：保持 | 固定当前值，停止进出水演示 | 等待命令，不自动回缩 |
| DRAINING：排水演示 | 从当前值平滑到 0 | 转为 RESTORED |
| RESTORED：已恢复 | `u=0`，保留一轮完成语义 | 等待下一轮 |

另设 `paused`，不新增一套几何状态：暂停冻结当前运动段的时间，继续时完成剩余过程。**保持会结束当前运动段；暂停会保留它。**

首版建议使用演示时间曲线：

```text
s = clamp(elapsed / duration, 0, 1)
u = u_start + (u_target-u_start) * (3*s*s - 2*s*s*s)
```

默认完整注水／排水各 6 秒，可作为演示配置调整；部分行程时长可按 `abs(u_target-u_start)` 比例计算。零行程立即完成，避免除零。使用 Godot 游戏时间，不使用系统墙钟；后续录像仍可复用确定性时间控制。

操作规则必须先固定：

- 注水或排水中反向操作：从实际当前 `u` 开始新段，取消旧段；保证位置连续。上述曲线不保证任意人工打断时速度连续，报告中应说明，不伪称力学响应。
- 同一目标的重复按钮不反复重置计时；任何时刻 `u` 有限且位于 `[0,1]`。
- 手动滑块：取消当前运动与自动循环，进入 HOLDING；滑块成为手动指定当前值的入口。
- 界面随动画反映充盈度时使用不触发信号的更新，防止反馈回调把动画误切成 HOLDING。
- 重置：明确的用户操作，取消运动、暂停及循环，立即恢复 `u=0` 和 REFERENCE。需要平滑回缩时使用排水按钮。
- 目标充盈度与实际充盈度分开。首版修改目标仅影响下一次注水，避免参数修改造成隐藏跳变。
- 保持／重置等人工命令优先于回归循环，不能被旧回调覆盖。

### P2.3：新增独立控制场景

建议入口 `res://irrigation_control_preview.tscn`，保留现有 R2 诊断场景。

界面包含注水、保持、排水、重置、暂停／继续；实际充盈度百分比、当前状态、目标充盈度、注排水演示时长；手动 `0～1` 滑块。保留 Reference／Mid／Expanded 快捷定位，统一转换为控制器的手动设值命令。

观察功能复用腔体／组织分别显隐、同视角比较、参考线、不透明剖切和局部定位；热力图作为可选诊断。正常模式下不显示未经标定的压力、mL 或 mL/s。实际位移上限不提供额外放大旋钮。

新场景先用独立显示节点，不挂接旧 `kidney_collision.gd` 的静态碰撞。该脚本只在初始化时创建碰撞，且选择首个网格；直接复用会让显示与碰撞失配。P2 不据此宣称内镜可以在动态腔体中安全运动。

### P2.4：做可重复的工程循环

默认测试序列可设为：参考 1 秒 → 注水 6 秒 → 保持 2 秒 → 排水 6 秒 → 已恢复 1 秒。每轮 16 秒，连续三轮共 48 秒游戏时间。这是回归测试，不是 P4 的展示视频时间线。

自动循环需显式触发；普通 HOLDING 不自动排水。跨阶段的大时间步应携带剩余时间，避免每个阶段丢失一帧导致循环漂移。

检查内容：

- 30／60／120 次每秒更新及不等时间步，在相同游戏时刻得到相同充盈度，按明确数值容差比较。
- 三轮末尾均恢复参考，固定点始终零位移；暂停期间段时间不增长，继续后剩余时间正确。
- 中途保持、反向、重置、拖动滑块、修改下一次目标、边界值重复操作均有确定结果。
- 五档几何快照使用精确目标 `u`；真实循环采样另外记录实际 `u`，不能把接近 0.25 的值冒充精确 0.25。
- 数学控制器测试与真实 Godot 网格输出相互核对，不能只验证控制器日志而不检查组织是否更新。

### P2.5：真实图形与性能验证

组织有 31 万余三角面。现有 R2 预览每次改变充盈度会重建坐标、法线与 ArrayMesh，并可展开逐面热力图；它适合诊断，不能直接认定为连续动画性能合格。

项目物理更新为 240 Hz。形变显示更新不放进每个物理 tick；`u` 未变化时不重复构建网格。相机、显隐或剖切参数变化也不应无条件触发几何重算。

先测量普通联合视图的坐标计算、法线计算、网格提交耗时，以及帧时间中位数／P95、实际 FPS 和内存变化。计划以稳定 30 fps 为展示目标，达到与否以真实运行记录为准；离线录制的 30 fps 不能证明实时性能。

若 CPU 重建过慢，单独优化数据缓存、更新路径或 GPU 形变方案，并重新核对顶点位置、法线、固定点与 float32 结果。不通过减小幅度、删面、跳过质量检查使性能表面达标。

在现有可用 Forward Plus 与 Compatibility 后端分别做启动和联合运动检查；不使用未经验证的大网格透明混合加景深方案。截图必须来自实际 Godot 运行。

## 5. P2 验收条件

1. 受保护输入哈希不变；无原始模型、旧成果或主场景改动。
2. 两份模型始终使用同一 `u`，运行时坐标与已验收公式一致；Reference／Mid／Expanded 与任意滑块值均正确。
3. 注水、保持、排水、暂停、重置、中途反向与人工打断通过测试；三轮往返无累计漂移，恢复参考精确。
4. 五档复核固定区、法线、面积、退化与翻面、有限三角形接触关系；沿用 R2 的边梯度 ≤0.2、面积比 0.8～1.35 等工程门禁，区分原有与新增问题。
5. 保留连续区间面积及法线方向分析。既有五档接触检查不等于整个连续区间的无碰撞证明；不虚构额外安全保证，也不每帧重复大规模几何扫描。
6. Godot 实际运行确认双网格一致性、稳定不透明观察方式和测得的性能；交付可复现命令、自动测试结果、真实截图及完整限制。
7. 用户在独立场景完成一次交互往返与局部检查，认可后再进入 P3。

已验收 R2 的参考指标：Expanded 最大边梯度约 0.112743；五档面积比约 0.890110～1.115126；F01 梯度约 0.003431，F02 面积比约 1.017634。这些是历史基线，不是本轮新执行的 P2 测试结果。

F03／F04 材料归属未确认、真实壁厚及生理参数未标定等限制继续保留。用户本轮认可的是现有工程几何成果；P2 不以补充解剖结论为前提重新开启 P1 映射研究。
