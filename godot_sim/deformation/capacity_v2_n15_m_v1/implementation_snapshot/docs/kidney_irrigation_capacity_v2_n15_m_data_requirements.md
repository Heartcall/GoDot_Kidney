# N1.5-M 合作资料需求与实施顺序

版本：2026-10-15-v1。优先审核现成影像、现有记录和合法可获取研究资料；本清单不是新增检查或人体灌注实验操作方案。新增医学采集、侵入性测压或加载条件须由医学负责人和伦理程序决定。

## 1. 已有与缺失

已有：工程D2、其源面／封口映射及哈希；16.805962087430178 mL参考几何量；原始OBJ、72标记、拓扑和N1量测；已验收P1/P2工程成果。用户说明成人、无结石梗阻或肾积水，CT排泄期未知、无前后影像／压力容量数据。

当前工作区没有实际原始影像／分割体素或配对时点数据。README记载忽略的原始CT目录，实际目录未找到；请将来由资料持有人核实是否仍有合法可用、可去身份化的原始数据。不要将目录名称当作采集时相或病史证明。未检索无关磁盘，不收集姓名、身份号码等资料。

## 2. 按路线划分的数据需求

“必需”是对所选推断路线而言，不要求为A额外取得B的侵入性资料。未知项可以存null，不能以估值补齐。

| 等级／路线 | 数据、定义／单位与状态 | 获取／D2对应、质量要求 | 当前已有 | 缺失阻碍／替代及局限 |
| --- | --- | --- | --- | --- |
| 必需 A/B/C | 操作性端点条件c_-、c_+，对象与时间窗 | 医学与用户先书面定义A未置械或B指定器械状态、出口、代表值规则；不得自行选压力／药物条件 | 未定义 | 没有被估计的对象；“正常最大”不能替代定义 |
| 必需 A | 同个体同侧、覆盖所定义两个条件的三维原始影像／分割，物理mm及容量mL | 先检查现成CT/MR/经验证3D超声；原生空间计容，合法去身份化关联码、完整视野和可读分辨率 | 缺失；仅README线索 | 无个体端点；群体资料只能产生条件性预测，不能冒充患者测量 |
| 必需 A/B/C | 医学测量域、UPJ／输尿管截止、肾盏终端、入口处理 | 原始掩码/方法/边界标注与D2源面/截环对照；明确不可映射空间，不重开D2 | D2已有；临床对照缺失 | 无绝对容量换算；仅mL相同或体积接近不够 |
| 必需 A/B（成像） | 采集状态、时间、时相、体位、排尿/膀胱、补液/利尿／出口和器械记录 | 已有影像元数据＋临床记录，经医学审核；状态窗口与所选端点相符 | CT时相及状态未知 | 两片的观测极值不能升级端点；可先只报告有标签的观测变化 |
| 必需 B（群体） | 健康成人按规定状态与测量域的原始分布及动态配对，容量mL | 原始论文全文、表格／数据使用许可；人数与双肾区分，健康／病理分开 | 仅E2线索；未取得同域配对原始数据 | 静态均值/SD不识别个体动态范围；不能补动物/儿童凑样本 |
| 必需 C | 绝对初始液体容量Vfluid,0，mL | 与压力/流量同次、同控制体的既有独立测量；加上器械/气体/结石占位再映射D2 | 无 | 只可识别ΔV；旧CT参考不是同步实验初值 |
| 必需 C | 同步时间s、Qin/Qout/Qleak或吸收、内源尿液，mL/s | 同一控制体、流量计平面、密度与单位、时延校正、漏液回收或有证据支持的界；零值也需证据 | 无 | 不能以注入袋体积当滞留量；漏液无界时ΔV也不可识别 |
| 必需 C／B | 局部压力P及测点、零点、单位与静/动态状态 | 既有合法记录，压力传感器标定/采样率、位置、体位与出口；设备供压不能替代 | 无 | 无P–V顺应性标定；仅影像容量路线可不拟合P |
| 必需 所有真实数据 | 来源、使用权限／许可、版本、SHA-256、去身份化与关联规则 | 数据持有人审核；公开摘要不等于原始数据许可；不发送身份信息或擅自联系作者 | 项目几何哈希有；临床数据无 | 不能追溯或合法复用结果 |
| 强烈建议 A/B | 独立读者重复分割、重复采集／时间窗内重复，mL和mm | 保留读者/方法编码，估计随机误差与共享偏差；按精度需求医学设计，不指定新检查次数 | 无 | 误差与真实变化混淆；文献方法误差只能提示风险，不能直接套本例 |
| 强烈建议 A/B | 体素间距／方向、层厚、序列、造影时相、分辨率和尺度校准 | 原始影像元数据，原生量测与配准Jacobian审核 | 仅工程RAS mm | 不能独立证实尺度/分割；网格数值误差不是临床误差 |
| 强烈建议 B | 年龄、性别、侧别、体型／BSA及健康筛查条件 | 合法去身份化协变量、排除标准；医学资料确认，不能由OBJ推断 | 仅“成人、无已报告梗阻/积水” | 限制外部有效性；不能把未知当作群体平均 |
| 强烈建议 C/B | 器械尺寸/长度/位置、工作通道占用、出口/鞘/吸引、膀胱和外部管路储液 | 同次既有记录；器械占位mL，净空与流阻分别处理 | 工程内镜有；临床同步记录无 | 流体量不等于几何量；静态器械模型不能证明当次边界 |
| 强烈建议 C | 加载/卸载标识、速率、循环历史、等待条件和温度 | 原始同步曲线、重复运行，不对混合分支强拟合 | 无 | 滞后与结构参数不可分；只报告测得分支范围 |
| 辅助 后续N2 | 已审阅局部截面、共享分叉、未知净截面与源面映射 | 复用N1；几何量与解剖分类分开 | 有；B27:25/B30:4独占净面积仍null | 可支持局部工程约束，不能直接给生理材料常数 |
| 辅助 后续N2/N3 | 同状态组织边界、接触与间隙资料 | 对照真实有限几何相交；不以表面最近距当壁厚 | 有旧0.2mm工程基线；无新临床形变 | 新幅度需重验；原基线通过不等于可放大 |
| 辅助 证据复核 | 研究原始全文/补充材料、方法定义、配对数据及许可 | 优先M03/M08/M09/M13/M27；Rousan分母/标签待澄清 | 阅读层级见矩阵 | 摘要不足以填分布；可保留方法线索但不拟合患者端点 |

公开资料优先级：①核实资料持有人是否有本例现成多状态影像；②通过合法机构访问取得E2方法/测量域全文及分布；③评估作者可申请数据的范围和许可。Nakagawa原站说明数据因隐私不公开、可合理申请；Rousan也仅说明可申请，当前未取得、不发送申请。即使取得健康群体数据，也不自动构成患者特异标定。[Nakagawa数据可用性](https://link.springer.com/article/10.1007/s12194-025-00952-9)、[Rousan数据可用性](https://pmc.ncbi.nlm.nih.gov/articles/PMC12381993/)。

## 3. 分阶段实施计划与批准点

| 下一研究批次 | 工作与输出 | 可通过条件／停止条件 |
| --- | --- | --- |
| M-A 条件定义与现有资料审核 | 用户与医学负责人选A/B、定义两个操作性状态；审核README原图线索、数据权限、状态覆盖 | 条件可审计且有合法资料；没有则明确缺口，真实参数保持null |
| M-B 域与误差可用性 | E2全文/数据复核；临床域↔批准D2映射与共享/状态依赖偏差；重复分割误差 | 有源边界、映射、误差与可识别性证据；未知部分不能任意补系数 |
| M-C 另行授权真实标定 | 优先配对同个体；必要时合法群体或P/Q研究；输出观测范围、区间及敏感性 | 不把未覆盖状态外推成端点；模型不足时保留非参数范围/null |
| M-D 端点共同审批 | 定义、来源、域、误差、区间、Reference夹持关系、外部有效性与限制 | 用户与医学共同批准；矛盾先复审，不能为通过强制Reference居中 |
| N2（须再授权） | 分别求解Contracted/Expanded；实际D2容量与全过程网格/组织门禁 | 容量目标与几何可行性同时通过；未解截面保守处理，失败不放宽门禁 |
| N3/P3/P4（独立后续） | 组织协调、器械与内镜路径净空、碰撞、显示性能及视频 | 标定不替代几何/路径安全；旧18～19FPS问题另行解决 |

后续研究没有预定临床数值、没有任意容量候选、没有要求用户立即进行医学检查。若资料始终不足，应交付“不可识别及缺失证据”研究结论，继续保留null，等待资料或正式需求重新审议。
