# N1.6之后：待批准的N2正式双向求解计划

版本2026-10-15-v1。仅计划；当前没有N2执行授权。建议用户先选择A1工程容量 **15.965664／16.805962／17.276823mL**，或明确选择其他目标及其已知风险。标签持续为 `MORPHOLOGY_GUIDED_UNCALIBRATED_CAPACITY_ESTIMATE`，不恢复生理端点前置条件，也不宣称临床极限。

## 1. 先冻结工程目标及测量策略

新建独立N2输入与配置，记录用户选定的Vmin_estimated/Vmax_estimated、D2批准与来源哈希、单位、N1站点、响应假设及限制。正式生理Vmin/Vmax/P/C/真实流量继续null，N1.5-M原结论不变。

明确移动D2边界的材料映射、虚拟封口构造及连续性；N1.6证明原封口三角化会在较大变化下产生风险，替代封口也可能有失败。不能仅选择某个时点可用的三角化而忽略切换造成的容量不连续。可研究有固定拓扑、受约束的测量封口，或有连续误差控制的更新策略；均需封口—壁面／自交、闭合、绕序及数值敏感性验证。测量封口仍不进入实体腔壁、组织或碰撞。

## 2. 独立双向区域联合优化

保持源顶点/面拓扑。以N1形态尺度与N1.6新响应作为**待复核初始猜测**，不能直接把研究offset标为正式N2。分别求解收缩与扩张的区域参数，独立目标与正则，不强制对称。

建议离线目标：形状保持／局部ARAP、拓扑支持的径向响应、窄区相对位移保护、细长三角面高度／面积保护、分叉共享连续性、接触相对运动和远场约束。硬约束包括实际D2容量、3675固定腔点、真实共点、面积／梯度、有限几何不新增穿越。区域响应不是由单一容量标量唯一决定，正则与响应假设需在配置中明示。

从一开始把组织接触可行性纳入腔体优化，不先锁定较大腔体形态再假设组织一定能跟随。N1.6中B30首先失败，较大扩张又扩散到其他天然分支，表明仅最近面软映射不足。需要在可靠有限配对上建立活动接触约束；材料共点严格一致，未确认近壁与F03/F04仍保守软约束。必要时增加组织空间支持或体内映射研究，不能用整体偏移／隐藏区域解决。

若用户选择S2或S3，其当前失败不等于绝对不可能，但必须先解决已定位的接触／质量阻塞并重新证明可行，不可沿用“目标体积已算到”作为验收。

## 3. 几何和容量验收门槛

| 项目 | 正式N2/N3须补足 |
| --- | --- |
| 容量 | 在正式测量封口策略下实际D2积分到批准目标；跨积分原点／方法复算，报告残差、闭合和边界敏感性 |
| 物理腔体与组织 | 原工程边梯度≤0.2、面积比0.8～1.35、固定点零位移、有限性、法线、无新增退化或翻面；不为通过调阈值 |
| 连续性 | J01～J09、B31/B32短过渡、T端帽、窄区、B26细长面及组织F01～F04全局和局部检查，不能转移畸变 |
| 相交 | 五档完整腔体／组织自身及相互有限几何检测；补足N1.6未扫描的中间组织自身检查；自适应中间采样／连续碰撞事件分析 |
| 原始接触 | 点／边、共面、近接触与横向穿越分开；原始与新增问题按几何位置、相交段、面积及相对运动解释，不只比较编号 |
| 组织空间关系 | 不把最近表面距离当壁厚；若不能确定内外壁和材料归属，限制必须保留，不能声称生理合理性已证明 |
| 实际显示 | 保持中心化[16,16,-81]mm；新float32坐标与实际ArrayMesh回读逐值核对，正确重算法线；独立新预览，不覆盖P2场景 |
| 人工验收 | Reference精确恢复；负侧、正侧及中间状态同视角检查；显隐／不透明剖切／热图／参考线，不扩大真实位移 |

解析面积／方向检查不是连续碰撞证明，采样没有穿越也不能保证所有时刻无穿越。无解或新失败应定位并停止，重新提交目标或区域响应建议，不能删除异常面、改变源网格或放宽门禁。

## 4. 状态、性能与展示衔接

未来几何编码`s=-1/0/+1`独立于容量和时间；两侧采用经积分验证的`V_D2(s)`，需要按容量控制时反查曲线。Reference既不是零容量，也不是范围算术中点。旧P2的u=0～1继续属于旧工程场，不直接改名为新最小—最大容量。

腔体与组织在同一新状态参数下同步更新，每次从Reference计算，不能累积位移。现阶段不修改旧控制器；正式新播放资源、格式和运行时回归另行实施。

旧18～19FPS问题仍未解决。以后优先离线求解并播放经过验证的形态；性能方案必须保持顶点／面精度和正确法线，不能删面或跳法线掩盖。若需要GPU路径，独立设计并逐值验证，不默认本轮离线原型解决了性能。

最终视频仍为“外部整体注排水形变→切换内镜视角→合格腔内路径运动”。视频内镜路径、器械包络、弯曲姿态与具体展示状态必须单独选择和净空验证；N1.6的静态中心路径距离只是局部探针，不能证明通镜。保留原静态碰撞系统，动态碰撞／内镜集成／录像另行授权。

当前停在容量选择与N1.6报告审核；不会自动启动上述任何正式开发。
